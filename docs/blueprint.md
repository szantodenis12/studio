# **App Name**: Hotel Maxim Experience

## Core Features:

- Hero Section: Interactive hero section showcasing the hotel's best features and premium rooms with high-quality images and videos.
- Room Showcase: Display available room types, prices and special offers using Nextjs's built-in image optimization for high-resolution previews.
- Spa & Wellness: Showcase the hotel's wellness features like spa, massage, fitness room, swimming pool etc
- Dining Experience: Showcase the available foods using the image optimisation features of nextjs
- Multilingual Support: Full website content available in Romanian and English using next-intl.

## Style Guidelines:

- Primary color: Deep midnight blue (#191970) to convey sophistication and tranquility.
- Background color: Very light grey (#F0F0F0), near white, to maintain a clean, airy feel.
- Accent color: Muted gold (#B8860B) for highlights, calls to action, and luxury touches.
- Font pairing: 'Playfair' (serif) for headlines to convey elegance, 'PT Sans' (sans-serif) for body text to ensure readability.
- React-based icon library with custom icons for amenities, services, and navigation; hover effects to provide interactivity.
- Sleek, modern layout with a focus on whitespace; grid system for responsive design; round buttons and smooth transitions for a luxury feel.
- Subtle animations throughout the site using Framer Motion, including entrance animations, parallax effects, and transitions between sections, to create a dynamic and engaging user experience.
